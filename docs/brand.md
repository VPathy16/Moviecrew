# MovieCrew identity

The interlocking-frame mark represents a film crew building one story. Use the flat SVG master in `moviecrew/portal/static/moviecrew-mark.svg`; preserve its proportions and clear space. The sidebar and home screen inline the same paths, and the browser icon uses the same mark.

| Token | Color | Use |
| --- | --- | --- |
| Ink | #17191D | Main canvas |
| Slate | #24272D | Panels and composer |
| Ivory | #F4F1EB | Primary text |
| Ember | #F27656 | Primary actions, selections and playhead |
| Mist | #A5ABB5 | Secondary text |

Keep accents sparse. Preview imagery retains its original colors. Avoid neon greens, decorative glow, gradients on the logo, or color filters over footage. Primary coral buttons use dark Ink text. Error and success states must also communicate their meaning with text.

# Vanaras — vision (founder's words, 28 Sep 2026)

Vanaras: one team of AI agents that takes care of you across phone (daily life), cloud (projects) and desktop
(work), with shared memory. Then the same for every employee in a company.

- Phone (like the Claude app): daily life — messages, calls, reminders, errands; what UNO does today.
- Cloud (like Claude Code on the web): your projects — agents keep working 24/7 while devices are off.
- Desktop (like Claude Cowork / computer use): your work — files, browser, apps.
- One team, shared memory, agents talk to each other and hand work between surfaces.
- Enterprise: every employee gets their own team, under the company's rules.

## Founder context
- Solo founder with a salary and ~$30K own capital; no need for side income.
- Built UNO (Android): scoped agents ("vanaras") each locked to their own tools; handover between agents;
  scheduled background jobs; approvals and spend rules enforced on the device; personal data never reaches the AI
  (reference tokens); service-agnostic MCP pipeline classifying tools by role; voice; BYO model key.
- Does not want: consumer food-app thinking, India-only, head-on fights with big tech.

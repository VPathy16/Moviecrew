## Best current answer: "AgentGuard — an open action firewall for Android agents"
- Core: rules + reconfirmation + sensitive-data tracking at the executor: target app in scope? element means
  Pay/Send/Delete/Grant? typed text a reference token or raw personal data? unexpected cross-app jump?
  Reuses UNO's tool-role classifier, scopes, approvals and reference tokens.
- Form: Python package wrapping each framework's action tool (droidrun, mobile-use adapters first) + thin Kotlin
  enforcer for on-device agents (Operit, UNO).
- New idea worth testing — agent attestation handshake: apps (via Appdome/Promon-style protection) block unknown
  agents but let GUARDED agents through if they present an attestation of the firewall's policy. This is a
  two-sided standard — the only part of v5 with network effects / company potential.
- Entry: coordinated disclosure of "Not an A11y" attacks to droidrun/minitap (neither has SECURITY.md) with a PR
  adding SECURITY.md + AgentGuard adapter.
- Credibility: public before/after benchmark on MobileWorldSafety / Not-an-A11y (co-author with Picek group).
- Money: bridge contract work (runway) → OpenAI Cybersecurity Grant (rolling, $10k increments) + NLnet Restack
  (€5–50k, deadline 3 Nov 2026; check non-EU eligibility & AI-content policy) → Seldon Lab / Catalyze (2027) →
  acqui-hire targets: Appdome, Promon, Guardsquare, NowSecure, Google Android security, droidrun/minitap.
- Incorporate only if ≥3 teams ask to pay (hosted runs / DMA evidence / attestation).
